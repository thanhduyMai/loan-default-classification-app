Credit Default Prediction App
A complete end-to-end machine learning project for predicting whether a customer will default on a loan. The project includes data preprocessing, model building, evaluation, and deployment as a web application using Streamlit and DuckDB.

🔍 Project Objectives
Analyze customer credit data to predict the likelihood of default.

Build interpretable and efficient classification models.

Deploy a user-friendly web app for real-time prediction.

🧰 Tools & Technologies
Python: Data analysis and model development

scikit-learn: Machine learning models

DuckDB: In-process analytics database for fast querying

Pandas & NumPy: Data manipulation

Streamlit: App deployment

Matplotlib & Seaborn: Data visualization

SMOTE: Handle class imbalance

⚙️ Features
Upload and explore credit data

Train models: Logistic Regression, Decision Tree, Random Forest

Use DuckDB for querying tabular data efficiently

Interactive web interface for default prediction

Display confusion matrix, ROC curve, and performance metrics

🚀 How to Run
Clone the repo:


git clone https://github.com/your-username/credit-default-predictor.git
cd credit-default-predictor
Install dependencies:


pip install -r requirements.txt
Run the app:


streamlit run app.py
📈 Results
Achieved over 85% accuracy on test data.

Deployed a working app to allow prediction based on user input.

Integrated DuckDB for lightweight and fast SQL queries on structured data.
